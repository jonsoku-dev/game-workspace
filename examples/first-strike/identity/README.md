# 달빛 아래 첫 일격 · 심벌 후보

[원크기 비교 시트](decision-sheet.png)를 100% 배율로 본다. 세 후보 모두 미채택이다. 파일을 복사한 사실은 미술 승인이나 엔진 통합을 뜻하지 않는다.

브리프의 근거는 프로젝트 `first-slice.json`과 README다. 달빛 아래 훈련 로봇이 표적에 접근하여 세 번 정확히 명중하는 게임이다. 차분함·정확함·짧은 타격을 디자인 방향으로 가정했다. 용도는 로컬 게임의 작은 심벌과 파비콘 후보이며, 대상 연령·브랜드 색·선택권자의 취향은 정해지지 않았다.

| 후보 | 형태와 의도 | 직접 본 원크기 관찰과 한계 |
| --- | --- | --- |
| A `a-moon-strike.svg` | 가는 초승달 옆에 분리된 사선으로 첫 일격을 표현한다. | 16px에서도 달과 사선이 분리된다. 32/128px에서 여백이 가장 편안하다. 달의 아래 끝은 16px에서 부드러워지고 로봇은 설명하지 않는다. |
| B `b-target-cut.svg` | 열린 사각 표적을 대각선이 가로지른다. | 작은 크기에서 각과 사선은 유지된다. 편집·외부 링크 도구 아이콘으로 오독할 수 있다. |
| C `c-robot-guard.svg` | 사각 머리와 두 눈, 안테나로 훈련 로봇을 단순화한다. | 16px에서도 두 눈은 남지만 입이 짧은 점에 가까워진다. 가장 직접적인 로봇이며 달빛·일격의 차별성은 약하다. |

시트를 직접 본 제작자의 임시 선호는 A다. 제목과 연결되는 형태와 작은 크기의 분리된 사선이 이유다. 사용자 선택·상표 적합성·미술 수용을 주장하지 않는다. 세 도안은 이번 작업에서 직접 작성한 기하 도형이며 알려진 로고와의 포괄적인 유사성 조사는 하지 않았다.

SVG 원본은 `studio/starter/identity/`의 같은 이름 파일을 바이트 그대로 복사했다. 텍스트·폰트·외부 이미지·스크립트 없이 128 단위 viewBox와 단색 면만 썼다. 밝은 배경용 SVG의 잉크는 `#102434`다. 어두운 배경용 PNG는 동일 도형의 잉크를 `#f3f0e7`로 바꿨다. 실제 그림의 투명 여백을 유지했다.

`*-light-16.png`처럼 테마와 크기가 붙은 PNG 18개는 투명 배경의 정확한 16/32/128px 래스터다. 시트에 넣을 때 크기를 바꾸지 않았다. 시트의 영문 표시는 비교 도구의 라벨이며 로고 일부가 아니다. SVG를 실제로 래스터화한 resvg-py 버전과 SHA-256은 [validation.json](validation.json)에 있다. XML 요소·속성 allowlist, 외부 자원 부재, 출력 크기와 투명 여백을 검사했다.

재검사는 resvg-py와 Pillow가 있는 Python에서 `python render_check.py`로 한다. 이 스크립트는 이 폴더의 파생 PNG·시트·validation.json을 다시 쓴다. 이번 실행은 `/tmp/first-strike-logo-raster`의 격리 환경에서 수행했으며 저장소 의존성은 추가하지 않았다. 별도 PNG 설치 없이 SVG 원본 자체를 사용할 수 있다.

방법은 [logo-design SKILL.md](https://github.com/kaankiziltug/logo-design-skill/blob/main/skills/logo-design/SKILL.md)의 브리프·대안·원크기 관찰 절차만 참고했다. 라이브러리, 폰트, 스크립트, 템플릿은 사용하지 않았다. 로컬 절차는 [LOGO.md](../../../studio/starter/identity/LOGO.md)를 따른다.

실제 브라우저 탭, 운영체제 아이콘 처리, 한글 제목 조합, 색각 조건, 상표 등록 가능성은 확인하지 않았다. 자동으로 파비콘을 선택하거나 게임에 적용하지 않았다. 그래프 등록은 통합 담당자가 실제 파일과 검증 근거를 연결한다.
