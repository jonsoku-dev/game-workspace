# 달빛 아래 첫 일격

달빛 아래 훈련 로봇이 표적을 향해 다가가 세 번 정확하게 내리친다. 공격 전 몸을 모으는 예비 동작의 길이를 비교하여 손맛을 다듬는다.

표적을 향해 이동한 뒤 유효한 공격을 3회 명중시키세요.

←/→ 또는 A/D: 이동 · Space: 공격 · R: 다시 시작. 화면 버튼도 사용 가능합니다.

아이디어는 원문으로 보존합니다. 첫 슬라이스는 이동·표적 명중 규칙으로 제한합니다. 임의 게임 규칙을 자동 해석하지 않습니다.

- 표적에서 멀리 공격하면 점수가 오르지 않는다.
- 표적을 바라보고 접촉 프레임에 명중해야 1점 오른다.
- 3회 명중 전에 완료되지 않고, 3회에 완료된다.
- R로 점수와 캐릭터 위치를 초기화한다.
