# 잿불 골목

두 던전으로 이어지는 오리지널 벨트스크롤 액션입니다. 첫 던전에서 폐공장과 제련로를 해방하면 완료 화면에서 **다음 던전으로 계속**을 선택해 사슬 승강장에 들어갑니다. 승강장에서는 정면 연타가 막히는 방패 수문장과 번갈아 분출하는 증기 구역을 상대합니다.

`genre.json`의 `stages`가 제목·목표·공략 문구의 원본입니다. 게임은 Studio 게시기가 주입하는 `./campaign.mjs`의 `loadCampaign()`을 사용합니다. 첫 완료는 `between`, 명시적 계속은 `advance()`, 패배는 `failed`, 현재 던전 재도전은 `retry()`, 마지막 완료는 `complete`, 전체 새 시작은 `restart()`입니다. 게임 폴더에 공용 캠페인·피드백 모듈을 중복 저장하지 않습니다.

```sh
python3 studio/tools/web_game.py --project examples/ember-alley --out play/local-test
python3 -m http.server 53021 --bind 127.0.0.1 --directory examples/ember-alley/play/local-test
node examples/ember-alley/tools/combat.test.mjs
node examples/ember-alley/tools/campaign.test.mjs
```

방향키/WASD로 네 방향 이동합니다. 위아래는 깊이축이므로 공격 범위를 벗어나 피할 수 있습니다. J는 3연격이며 타격 중 다시 누르면 다음 검격을 예약합니다. K는 3.8초마다 적을 띄워 공중 추격을 엽니다. Space는 입력 방향으로 회피하며 재사용은 1.05초입니다. 예고 공격이 닿기 직전 140ms 회피에 성공하면 1.35초 동안 다음 기본 공격이 반격으로 바뀝니다. 반격은 피해 18을 더하고 첫 던전 감독관의 가드를 끊습니다.

첫 던전의 두 방은 각 두 차례 봉쇄됩니다. 첫 방을 정리한 뒤 오른쪽 문 가까이에서 Enter로 제련로에 들어가며 체력 28을 회복합니다. 감독관은 좁은 깊이의 쇄도와 표시된 지점의 넓은 분쇄를 번갈아 예고합니다.

사슬 승강장의 수문장은 방패 방향을 고정합니다. **뒤쪽** 표시로 돌아가 J를 맞히거나 정면에서 K를 쓰면 방패가 2.6초간 개방됩니다. 정면 J와 정면 반격은 방패에 막히며 피해·점수를 주지 않습니다. 개방 중 연격은 정상 명중하고, 뒤쪽에서 처음 개방하면 추가 피해 6을 얻습니다. 방패는 시간이 지나면 복구됩니다. 마지막 수문장은 반대쪽을 바라보므로 두 번째 진입 방향도 읽어야 합니다.

증기 구역은 상단·하단·중단 순서로 바뀝니다. 바닥의 삼각형·점선 윤곽이 0.95초 먼저 경고하고, 0.70초 분출한 뒤 냉각됩니다. 다른 깊이로 이동해 피하세요. 한 주기의 증기 피해는 최대 한 번이며 회피 무적으로 분출 전체를 버틸 수 없습니다. 동작 줄이기에서는 움직이는 증기와 화면 흔들림을 생략하고 경고 윤곽·문구·정적 증기는 유지합니다. 방패에 막힌 접촉은 청회색 꺾임, 실제 타격은 몸 가까운 작은 섬광, 방패 개방은 녹색 문구로 구분합니다.

던전을 계속하면 점수·처치·최대 연격·누적 전적을 이어가며 체력 32를 회복합니다. 패배 후 **이 던전 재도전**은 그 던전 입장 시점의 점수·전적·체력으로 복구하므로 중간 점수를 반복 획득할 수 없습니다. R은 언제나 첫 던전부터 점수 0으로 새로 시작합니다. Enter는 열린 문 또는 완료 후 다음 던전으로 계속, P는 일시정지입니다. 화면 버튼은 키보드·포인터 조작을 지원하며 방향 버튼은 누르는 동안 이동하고 해제·초점 이탈 시 멈춥니다.

런타임 자원은 모두 상대 경로입니다. 소리는 기본적으로 꺼져 있고 사용자가 선택할 수 있습니다. `combat.mjs`가 판정과 전투 규칙, `progression.mjs`가 플러그인 상태와 입장 기준 복구를 담당합니다. `window.emberState`는 브라우저 증거용 읽기 전용 복사본이며 조작 API가 아닙니다. 자동 검사와 실제 브라우저 관찰, 청취·사람의 미술 승인은 각각 구분합니다.
