# 빙정 종탑

설치한 Game Studio 0.15.0에서 `web_game.py --init-combat --combat-brief "$STUDIO_ROOT/starter/combat-brief/falcon.json"`로 생성했다. 직업별 제작 지시서는 [art-direction.md](art-direction.md), 새 기술 원화는 [custom-0.webp](game/fx/custom-0.webp)다.

[비교판](checks/asset-review-1c0a250ba1474becb0c548ccf08589e5/review.html)에서 빙정사수의 실루엣과 여섯 노출을 공명기사에 대조한다. 정상 납품은 `play/first`이고 HTTP 서버에서 [게임](http://127.0.0.1:41750/)을 연다. 브라우저에서 명중 3회와 빗나감 1회를 확인했다. 자동 검증은 미술 채택을 뜻하지 않는다.
