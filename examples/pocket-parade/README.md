# 포켓 무리

같은 동물 3마리 이상을 가까운 순서로 이어 놓으면 터지는 75초 실시간 퍼즐입니다. 64개의 공이 중력과 충돌로 쌓이고 빈자리는 위에서 다시 채워집니다. 고정된 칸이나 회전 타일은 사용하지 않습니다.

- 같은 종류·가까운 거리만 연결됩니다. 같은 공을 재사용할 수 없고 직전 공으로 돌아가면 한 단계 취소됩니다.
- 점수는 연결 수의 제곱 × 25입니다. 7마리부터 주변 보너스가 생깁니다. 24마리를 모으면 8초 동안 점수가 두 배입니다.
- 목표는 6,000점입니다. 흔들기는 5초 간격으로 쓸 수 있습니다. 일시정지·탭 숨김은 타이머를 멈춥니다.
- 마우스·터치는 누르고 이어서 놓습니다. 키보드는 게임판에서 방향키로 친구를 고르고 Space로 잇고 Enter로 확정합니다. Escape로 취소합니다.
- 소리는 기본 꺼짐이며 사용자가 소리 버튼을 누르면 활성화됩니다. 감속 동작 설정에서는 장식 애니메이션을 생략합니다.

`game/`은 배포 입력입니다. 배포기는 공유 `feedback.mjs`를 주입해야 합니다. 아트 원본과 정규화 기록는 `art-source/`에 있습니다. 실제 소비하는 에셋은 `game/art/plush-{bunny,bear,cat,frog}.png`입니다.

규칙 검사는 `node examples/pocket-parade/tools/verify.mjs`입니다. `tools/browser-check.py`는 구성된 공식 Stagehand MCP로 실행합니다. 현지 Stagehand의 `mouse.down`은 실제 누름을 보내지 않으므로 포인터 경로 검사는 합성 PointerEvent로 표시합니다. 물리 마우스·터치 장치 검증과 구분해야 합니다. 배포와 그래프 등록은 상위 작업이 담당합니다.
