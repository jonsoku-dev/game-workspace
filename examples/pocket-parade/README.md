# 포켓 무리

64개의 봉제 동물이 중력과 충돌로 쌓이는 두 라운드 연결 퍼즐입니다. 같은 동물을 가까운 순서로 3마리 이상 이어 놓으면 구조하고 위에서 다시 채웁니다. 고정 칸이나 회전 타일은 사용하지 않습니다.

## 두 주머니의 다른 목표

1. **작은 주머니 구조대**. 75초 안에 60친구를 구조합니다. 20마리마다 배지를 얻습니다. 60마리를 채우면 시간 종료를 기다리지 않고 완료 버튼을 누를 수 있습니다. 승리 화면에서 다음 주머니를 명시적으로 열어야 진행합니다.
2. **별실 수선실**. 90초 안에 왼쪽·오른쪽 두 솔기를 수선합니다. 같은 동물 7마리 이상의 연결을 표시 가까이에서 끝내면 마지막 위치에 별 단추가 남습니다. 별 단추의 폭발 범위가 솔기 표시를 덮을 때만 수선됩니다. 친구 수나 점수만 올려서는 이 라운드를 끝낼 수 없습니다. 단추에 초점을 놓으면 실제 수선 범위를 볼 수 있습니다.

일반 구조·솔기 빗나감·수선 성공·두 솔기 완성의 문구와 반응을 구분합니다. 별 위치의 국소 파동과 수선 부위의 패치·실선으로 결과를 보여줍니다. 장식 동작은 `prefers-reduced-motion`을 따릅니다. 별 단추로 수선한 솔기는 다시 점수나 진행으로 세지 않습니다.

## 조작과 공정한 재시도

- 마우스·터치는 누르고 이어서 놓습니다. 같은 종류·가까운 거리만 연결하며, 재사용할 수 없습니다. 직전 친구로 돌아가면 한 단계 취소합니다.
- 키보드는 게임판에서 방향키로 친구를 고르고 Space로 잇고 Enter로 확정합니다. Escape로 취소합니다. 별 단추는 Tab으로 선택한 뒤 Enter·Space로 사용합니다. 별 단추와 완료·다음·재시도는 표준 버튼입니다.
- 2라운드는 시작 전에 수선 방법을 설명합니다. 각 솔기 주변에 긴 연결이 가능한 고정 시드를 사용하고, 연결이 끊기면 화면 안의 가까운 친구 7마리를 같은 동물로 정리합니다. ‘실 정리’도 이 보조 경로를 준비합니다. 잠깐의 빛 반응과 안내 문구로 변화를 알립니다.
- 점수는 연결 수의 제곱 × 25이며 피버 중에는 두 배입니다. 24친구를 연결하면 8초간 피버입니다. 별 구조는 친구당 75점, 새 솔기는 추가 500점입니다.
- 다음 라운드에는 점수를 가져갑니다. 실패 후 재시도는 **현재 라운드의 진입 점수·고정 배치**부터 시작하므로 실패로 점수를 누적할 수 없습니다. 전체 처음부터는 1라운드·0점으로 초기화합니다. 일시정지·탭 숨김·라운드 설명에서는 시간이 멈춥니다.
- 소리는 기본 꺼짐이며 사용자가 소리 버튼을 눌러 활성화합니다.

## 런타임 계약과 검증

`genre.json`의 `stages`가 제목·목표·전술의 원본입니다. 배포기는 공유 `feedback.mjs`와 `campaign.mjs`를 주입해야 합니다. 게임은 `loadCampaign()`의 `index`, `stage`, `phase`를 읽고 `finishStage`, `advance`, `failStage`, `retry`, `restart`의 boolean 결과를 따릅니다. 게임 소스에서 이 모듈을 복제하지 않습니다. 아트는 별도 담당자가 `game/art/`에 공급합니다.

- `node examples/pocket-parade/tools/verify.mjs`. 연결·충돌·보너스·솔기 경계·빗나감·안전한 실 정리의 순수 규칙 검사입니다.
- `node examples/pocket-parade/tools/campaign-route.mjs`. 실제 게임 입력 처리기를 DOM과 캠페인 계약 fixture에서 실행해 구조→명시적 다음→잘못된 위치→수선→실패→동일 라운드 재시도→두 솔기 완성→전체 초기화를 검사합니다. fixture 시간 진행은 실제 브라우저의 자연 타이머 증거가 아닙니다.

설치된 배포본의 실제 캠페인 모듈·브라우저 검증·그래프 등록은 상위 작업이 수행합니다. 기존 Stagehand의 누른 채 마우스 이동은 지원되지 않으므로 합성 PointerEvent 검사와 실제 클릭·물리 장치 증거를 구분해야 합니다.
